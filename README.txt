# Refugio — Diseño de interfaz

## Archivos
- `index.html`: estructura de la página principal.
- `css/styles.css`: estilos, distribución y adaptación responsive.

## Cómo visualizar
Abrir `index.html` en un navegador. No requiere instalación ni servidor.

## Consideraciones
- Es una maqueta visual de la página principal, no está conectada a una base de datos.
- Los nombres, importes y cantidades son datos ficticios de demostración.
- Los enlaces del menú representan las secciones previstas para el sistema.
- Se utilizó HTML semántico y CSS separado, sin frameworks ni JavaScript.
- La tipografía se carga desde Google Fonts; si no hay conexión se utilizan fuentes alternativas.
